# Zakkey

レースゲームを中心に、MODや周辺ツールを作っています。

アイデアはある。技術はAIと一緒に調達中。  
動くものを作り、壊れたら直します。

> [!NOTE]
> **AI-assisted development**
>
> このアカウントでは、Codex・CursorなどのAIを開発ツールとして積極的に使用しています。  
> AIを使った制作が苦手な方は、そのままブラウザの「戻る」へどうぞ。引き止めません。  
> AIの利用は隠さず、公開する成果物では動作確認と記録を大切にしています。

## Working style

- AIの利用箇所を隠さない
- ソース、検証手順、既知の制限をできるだけ残す
- 「起動した」と「正常に遊べた」を分けて考える
- ゲーム本体のデータや権利者のコンテンツを再配布しない
